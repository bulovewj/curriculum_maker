내 손 안의 교육과정은 학교가 이미 가진 파일을 넣으면 진도표·시간 운영계획·NEIS 업로드 엑셀까지 뽑아 주는 학년 초 교육과정 설계 웹 서비스다. 목표는 2028학년도 편성 시즌에 신명초에서 스쿨마스터를 완전히 대체하는 것이고, 1차(목표 2027년 2월)는 6학년의 '파일 → 진도표·엑셀' 흐름이다.

## 한 장 요약

학교가 해마다 만드는 파일을 넣으면 진도표·시간 운영계획·시수증감 계획·NEIS 업로드 엑셀이 한 번에 나오는 웹 서비스를 만든다.

## 기존 도구와 대체 계획

스쿨마스터는 시수 편제부터 NEIS 업로드 엑셀까지 대부분을 이미 하지만, 설치형이라 함께 편집할 수 없고 외부강사·어울림·진로 기능이 없다. 내 손 안의 교육과정은 교육과정 설계·운영 기능을 모두 대체하고, 학생 정보가 들어가는 평가 기능은 대체하지 않는다.

### 스쿨마스터 한눈에

- 초등 교사용 연간 교육과정 작성 프로그램, PC 설치형(윈도우 전용으로 보임)
- 가격: 개인 2만 원, 9학급 이하 10만 원, 40학급 44만 원. 라이선스 기간 표기는 없고, 해마다 새 버전을 내는 것으로 보임
- 학교·학년 교육과정은 클라우드에 올리고 내려받아 공유, 학생 명부·성적은 교사 PC에 암호화 저장
- 질문게시판 제목에 4세대 나이스 자동 입력 오류, 한글 변환 오류, 창체 시수 계산 문의가 반복됨

### 다른 도구와 NEIS

- 한국교육과정평가원: 시수 계산·담임·전담 배치·시간표 생성 AI 시제품을 2026년 8개 학교에서 실증. NEIS 연동은 향후 과제, 보급 계획 미정
- 경북 학교자율시간 설계 챗봇(과목명·학년·시수를 넣으면 목표·차시·평가 계획 생성), 부산 PenGPT(교원용 AI 비서)
- NEIS: 학급 시간표와 교과진도표를 동기화해 날짜별 진도를 만든다. 학기별 시간표는 시수편차 0으로 맞춰 저장한다. 공식 쓰기 API는 없어 보여, 연동은 ‘업로드용 엑셀’이다. 읽기는 초등 시간표 오픈 API가 있다.

## 목표와 범위

목표는 스쿨마스터의 교육과정 설계·운영 기능 완전 대체, 쓰기 편한 화면과 흐름, AI 기능 추가 세 가지다.

### 목표

1. 완전 대체: 2028학년도 편성 시즌(2028년 1\~2월)에 신명초가 스쿨마스터 없이 학년 초 교육과정을 설계하고 NEIS까지 넣는다.
2. 편의성: 설치 없이 웹에서, 파일만 넣으면 되고, 같은 숫자를 다시 치지 않는다.
3. AI: 파일 읽기, 재구성 제안, 증감 사유·자율·자치 활동·어울림·프로젝트·진로·학교자율시간 운영안 초안을 만든다.

### 대상

- 부산 초등학교. 1호 학교는 신명초(2026년 43학급: 1학년 5, 2학년 7, 3학년 6, 4학년 8, 5학년 9, 6학년 8)
- 2022 개정 교육과정(초등 전 학년 적용은 2026학년도에 완료)

### 범위 안

- 필요 자료 9종: 학년별 시수·창체 편성, 학사일정·행사, 출판사별 진도표, 전담·학급 시간표, 강사진도표, 어울림, 주제중심 프로젝트, 진로교육 계획, 교과 증감 시수 운영 계획
- AI 활용 9종: 진도표 자동 조절, 자율·자치 자동 입력(주제어), 전담·학급 시간표 설정, 학급 시간표 편차 조절(전담 고정), 강사진도표·어울림·프로젝트·진로·증감 계획 자동 생성
- 학기 운영 2종: 시간표 실시간 공유, 전담 변경 때 시수 자동 체크
- 스쿨마스터의 교육과정 설계·운영 기능 전부(기존 도구 표)

### 범위 밖

- 학생 정보가 들어가는 기능: 평가 기록, NEIS 평가 의견 자동 입력, 반편성, 학생 명부
- 전문적학습공동체, 수업장학, 동아리 부서 조직, 위원회, 부서별 업무계획서(학교교육계획서). 단, 동아리 시간은 고정 칸으로, 수업장학 날짜는 행사로만 받는다.

| 담임 | 자기 반 담임 칸 조정, 주간학습안내 | 자기 반 담임 칸(편차 검사 동반), 나머지는 보기 |
| 전담 | 자기 전담 시간 확인 | 보기 |
| 외부강사 | 자기 일정 확인 | 로그인 없는 보기 링크 |

- 로그인: 구글 계정(안 되면 이메일 링크). 교육과정 담당이 보낸 학교 초대 링크로 가입한다.
- 묶음: 위 표의 기본 권한을 한 번에 주는 묶음을 제공한다. 교과 단위 권한은 4차 이후 필요하면 만든다.
- 제출·확정(3차): 학년이 ‘제출’ → 교육과정 담당이 검토·‘확정’ → 확정 뒤 수정은 누가·언제·무엇을 바꿨는지 이력이 남는다. 지금의 드라이브 폴더 제출을 대신한다.
- 동시 편집: 같은 화면을 두 사람이 열면 ‘○○ 편집 중’을 보여 주고 먼저 연 사람만 편집한다.

## 설계 원칙

모든 문서는 ‘학급별 1년치 수업 칸 표’ 하나에서 뽑는다. 아래 원칙은 그릴미 인터뷰에서 확정했다.

1. 단일 원본: 학급마다 \[수업일 × 교시\] 칸을 1년치 깔고, 칸마다 교과·창체 영역, 담당(담임·전담·강사), 진도 항목, 태그를 둔다. 진도표·시수표·강사 일정·증감 계획·학기 중 시간표는 이 표를 다르게 보여 주는 화면이다.
2. 파일 넣기가 기본: 학교가 이미 만드는 파일을 넣으면 AI가 읽고, 원문과 나란히 보여 주고, 교사가 확인한다. 표준 엑셀 양식과 화면 수정은 보조다.
3. 순서형 안내 + 자동 재계산: 처음엔 9단계를 순서대로 안내한다. 이후 어느 단계든 고치면 뒤 단계가 다시 계산되고, 사람이 직접 고친 칸은 잠가서 덮어쓰지 않는다.
4. 계산은 알고리즘, 글은 AI, 확정은 교사: 진도 배치·시간표·편차·시수 검사는 매번 같은 결과가 나오는 알고리즘으로 한다. 활동명·사유·계획 초안은 AI가 공식 목록(성취기준, 어울림 모듈, 진로 성취기준)에서만 골라 쓴다. AI를 꺼도 계산 기능은 모두 돌아간다.
5. 교과 증감은 방침 → 집계: 1단계에서 학교 방침(예: 학교자율시간을 확보하려고 국어 등에서 감축)을 넣고, 9단계에서 실제 이동을 모아 문서를 쓰고 규정을 검사한다.
6. 범교과·법정 태그: 칸마다 태그를 달아 학년별 충족률을 자동으로 센다. 기준은 해마다 배포하는 부산 기준 데이터(근거 표시)이고, 학교는 자기 사정만 덮어쓴다.
7. 반별 시수 = 편제: 반마다 연간 교과 시수를 편제와 맞춘다. 전담 칸은 고정이고, 학년 진도표는 대표 학급 기준이다.
8. 학교자율시간 = 학교가 만든 과목: 교과처럼 칸 표에 넣고, 자체 성취기준·차시 계획을 진도 데이터로 다룬다.
9. 행사는 정해진 칸으로: 기간, 대상 학년·학급, 하루 교시 수 변화, 시수 귀속(창체 영역·교과·시간), 범교과 태그. 행사 종류별 기본값을 주고, 기존 자유 글은 AI가 칸으로 바꿔 제안한다.

## 작업 흐름

9단계를 순서대로 안내하되, 3단계(진도 자료)와 4단계(시간표)가 모이면 진도가 자동으로 배치된다. 5\~8단계가 칸을 쓰면 진도가 다시 배치되고, 9단계가 그 결과를 집계한다.

| 단계 | 넣는 파일 | 프로그램이 하는 일 | 나오는 것 | 차수 |
| --- | --- | --- | --- | --- |
| 1 시수·창체 편성 | 교육과정 편제(안), 시수증감 서식 | 학년군 2년 단위 편제, 증감 방침 기록, 규정 검사 | 편제표, 검사 결과 | 1차 |
| 2 학사일정·행사 | 학사일정(안), 행사 목록 | 수업일·휴업일, 요일별 교시, 행사의 교시 변화·시수 귀속, 주별·월별 수업일수 | 학사력, 학년별 수업시수 변동 | 1차(파일), 2차(달력 편집) |
| 3 출판사별 진도 | 교과서 선정 목록, 출판사·작년 진도표 | 순수 교과서 차시 추출(단원·차시·주제·쪽수), 재구성·행사 행 분리 | 교과별 차시 목록 | 1차 |
| 4 전담·학급 시간표 | 전담 배정표, 시간표(구글 시트·엑셀) | 기초 시간표 → 1년치 칸 표, 반별 연간 시수 → 진도 자동 배치 | 시간 운영계획, 교과 진도표, 시간표 | 1차(파일), 2차(편집·자동 채우기) |
| 5 강사진도표 | 강사 출강 요일·교시, 학년별 차시 | 학급별 강사 칸 배치, 차시 내용 | 강사 일정표, 월별 실적·금액 | 3차 |
| 6 어울림 | 작년 어울림 계획, 역량별 시수 | 6개 역량 × 교과연계·창체 배분, 칸 배치 | 어울림 운영 계획 | 4차(AI 초안) |
| 7 주제중심 프로젝트 | 작년 프로젝트 계획, 주제어 | 관련 성취기준·교과 묶기, 재구성 | 프로젝트 학습 계획 | 2차(수동), 4차(AI 초안) |
| 8 진로교육 | 작년 진로 계획 | 진로 성취기준 기반 차시 계획, 칸 배치 | 진로교육 계획 | 4차(AI 초안) |
| 9 교과 증감 시수 운영 계획 | (자동) | 1단계 방침 대비 실제 이동 집계, 사유 문장 초안, 규정 검사 | 시수증감 운영계획 | 1차 |

## 기능 명세

기능은 16개 모듈이고, 1차는 M1\~M7이다. 1차만으로 ‘파일 넣기 → 진도표·엑셀’이 처음부터 끝까지 이어진다.

### M1 파일 넣기·AI 해석 (1차)

- 준비물 체크리스트: 학사일정·편제(안), 시간표, 교과서 선정 목록, 출판사 또는 작년 진도표, 학교자율시간 운영(안), 전담 배정표
- 받는 형식: hwp, hwpx, xlsx, 구글 시트 링크, pdf
- 처리: 표 추출(병합 칸 보존) → AI가 항목에 맞춰 구조화 → 원문과 나란히 보여 주고 자신 없는 칸은 노란색 → 교사 확정
- 표기 정리: 제각각인 날짜 표기, 원문자 휴일(②, ㉙), 글자 계산식(‘영4\*2=8’)을 풀어 숫자로
- 표준 엑셀 양식: 채우면 AI 없이 그대로 들어감

### M2 편제·규정 검사 (1차)

- 학년군 2년 단위 편제(1·3·5학년 편제 때 다음 해까지), 교과(군)·창체 영역·학교자율시간
- 증감 방침 입력(예: 학교자율시간 32시간을 어느 교과에서 확보하는지)
- 검사: ±20%, 체육·예술 감축 불가, 정보 34시간, 1\~2학년 안전 64시간, 학년군 최소 시수, 수업일수 190일. 검사마다 근거(고시 번호·쪽) 표시

### M3 진도 데이터 (1차)

- 교과서 선정 목록으로 교과별 출판사를 지정
- 출판사 진도표·작년 진도표에서 순수 차시 추출: 단원, 차시(n/N), 학습 주제, 쪽수, (있으면) 성취기준
- 작년 진도표의 ◆재구성·◈행사 행은 따로 보관(재구성 이력은 다음 해 참고용)
- 학교자율시간: 운영(안)의 차시별 지도계획(성취기준·주제·시기·시수)을 진도 데이터로

### M4 칸 표 생성 (1차)

- 학사력 + 학년별 요일 교시 패턴(2026 신명초: 1·2학년 4·5·5·5·4, 3·4학년 5·6·5·5·5, 5·6학년 6·6·5·6·6) + 행사 교시 변화 → 학급·날짜·교시별 칸
- 기초 시간표(요일×교시 → 교과·담당)를 칸에 채우고 행사 칸으로 덮어씀
- 반별·주별·월별·학기별 교과 시수 집계

### M5 진도 자동 배치·재구성 (1차)

- 교과마다 차시 목록을 그 교과 칸에 순서대로 배치(대표 학급 기준, 주 단위 진도표)
- 편제 시수와 차시 수가 다르면 감축·증배할 양을 계산 → AI가 후보(합칠 차시, 늘릴 단원, 관련 성취기준) 제안 → 교사 확정
- 태그: ◆재구성(감축·증배), ◈행사, 【범교과】, 어울림. 2026 진도표 표기와 같다.
- 날짜 고정 차시, 연차시 묶기
- 창체: 자율·자치 시간에 주제어(범교과 태그)를 고르면 주차별 활동 이름을 AI가 채움

### M6 시수 점검 (1차)

- 편제 대비 교과별·창체 영역별 연간·학기 시수, 반별 편차, 법정·범교과 충족률, 수업일수, 월별 미달 경고
- 문제마다 ‘어디서 몇 시간’과 근거를 보여 줌

### M7 출력 (1차)

- 교과별 연간 진도표(hwpx): 주, 기간, 단원명, 학습 주제, 차시, 쪽수, 비고(태그). 2026 6학년 양식을 표준으로
- 학년 시간 운영계획(hwpx): 주 × 교과·창체 시수, 학기·연간 계, 본교 편제 시수·증감 현황
- 시수증감 운영계획(hwpx): 교육부 기준·본교 운영·증감 표 + 증감 행(학기, 교과, 영역, 관련 성취기준, 관련 단원, 주요 내용, ±시수)
- NEIS 업로드 엑셀(교과진도): 양식을 확보한 뒤 구현
- 시수 점검표(xlsx·hwpx), 시간표(xlsx·구글 시트)
- hwpx 표가 쪽을 넘으면 자동으로 나눠 다음 쪽 표로 이어 씀

## 화면 흐름

**(그림) 1차 화면 흐름** — 파일을 넣고 확인하면 진도표와 NEIS 엑셀까지 한 줄로 이어진다

1 학교·학년도 만들기 → 2 준비물 올리기 → 3 해석 확인 → 4 편제·규정 검사 → 5 진도 배치·재구성 → 6 시수 점검 → 7 내보내기

- 표준 엑셀 양식이면 2에서 바로 4로 간다(3 해석 확인 생략).
- 6에서 문제가 있으면 고치고, 뒤 단계는 자동 재계산된다(6 → 5).
- 7 내보내기: 진도표·운영계획·증감계획 hwpx, NEIS 엑셀. 2027년엔 스쿨마스터 결과와 나란히 비교한다.

1차는 화면 7개로 끝난다. 사람이 손대는 곳은 3단계 해석 확인과 5단계 재구성 확정이고, 6단계에서 문제를 고치면 뒤 단계가 자동으로 다시 계산된다.

## 데이터 구조

중심은 ‘칸(slot)’ 테이블이고, 나머지 테이블은 칸을 만들거나 칸에서 집계한다.

## 계산 알고리즘

진도 배치·편차 조절·규정 검사는 같은 입력이면 같은 결과가 나오는 알고리즘이고, AI는 후보와 문장만 낸다.

1. 수업일·교시 계산(1차)
   - 학사력에서 수업일을 고르고, 학년별 요일 교시 패턴을 적용한 뒤 행사의 교시 변화(예: 수학여행 주 7교시)로 덮어쓴다.
   - 두 달에 걸친 주를 어느 달로 셀지는 학교 설정이다. 2026 신명초는 3월 30일 주를 4월로 셌다.
2. 칸 표 생성(1차)
   - 기초 시간표를 적용 기간 동안 수업일 칸에 채운다. 행사 칸은 행사의 시수 귀속대로 교과·창체 영역을 바꾼다.
3. 진도 배치(1차)
   - 교과마다 차시 목록을 그 교과 칸에 날짜순으로 하나씩 놓는다. 날짜를 고정한 차시는 먼저 놓는다.
   - 편제 시수 − 차시 수 = 재구성할 양. 모자라면 감축 후보(합칠 차시, 주제 중심 활동으로 바꿀 단원), 남으면 증배 후보를 AI가 내고 교사가 고른다.
   - 확정된 재구성은 adjustment 행이 되고, 9단계 증감 계획에 그대로 쓰인다.
4. 규정 검사(1차)
   - 기준 데이터의 규칙마다 ‘통과·경고·위반 + 어디서 몇 시간 + 근거’를 낸다.
5. 담임 칸 자동 채우기(2차)
   - 조건: 주당 교과 시수, 하루 같은 교과 상한(학교 설정), 고정 칸(예: 수요일 5교시 동아리), 블록 수업.
   - 조건을 모두 지키는 배치를 찾고, 못 찾으면 어느 조건 때문인지 보여 준다.
6. 반별 편차 조절(2차)
   - 반마다 교과별 연간 시수를 세서 편제와의 차이를 구한다.
   - 담임 시간표를 정할 때 공휴일이 몰린 요일을 감안해 배치하고, 남는 차이는 특정 주의 담임 칸 맞바꾸기로 메운다.
   - 전담 칸은 움직이지 않는다. 전담 교과가 모자라면 경고하고 보충 후보 시간을 낸다. NEIS도 학기별 시간표를 시수편차 0으로 맞춰야 저장된다.
7. 전담 변경 재검사(4차)
   - 학기 중 전담 수업을 바꾸면 해당 칸만 다시 세서, 반별 연간 시수가 편제에 미달하는지 바로 알려 준다.

## 기술 구조

**(그림) 기술 구조** — AI는 서버 함수 한 곳에서만 부르고, 학교 데이터는 서울 DB에 학교별로 나뉜다

- 교사 브라우저: 웹 화면(React + TypeScript — 파일 올리기·해석 확인·진도·시간표 편집), 계산 엔진(TypeScript 순수 함수 — 칸 표·진도 배치·규정 검사)
- 서버 함수(Vercel, Python): 파일 해석(hwp·hwpx·xlsx·pdf → 표), 문서 만들기(hwpx·xlsx, 쪽 넘김 처리), AI 관문(역할명 가리기, 학교별 월 한도) → LLM 공급자(교체 가능, 역할명만 받음)
- Supabase(서울 지역): DB(Postgres — 칸 표·편제·진도·기준 데이터), 로그인·RLS(구글·이메일 링크, 학교별 분리), 파일 저장소(올린 파일·만든 문서), 실시간(4차 — 시간표 공유·전담 변경 알림)
- 연결: 브라우저 ↔ Supabase(읽기·쓰기), 브라우저 → 서버 함수(요청), 서버 함수 ↔ Supabase(파일·문서). NEIS(업무망)는 쓰기 API가 없어 교사가 엑셀을 직접 올린다.

화면과 계산 엔진은 브라우저에서 돌고, 파일 해석·문서 만들기·AI 호출은 Python 서버 함수가 맡는다. NEIS에는 쓰기 API가 없어서 교사가 내려받은 업로드 엑셀을 직접 올린다.

- 개발: VS Code + Claude Code, 코드는 GitHub에 두고 Vercel로 배포한다.
- 착수 문서: 이 기획서로 CLAUDE.md·작업지시서·CODING\_PLAN을 만들고 시작한다.
- 계산 엔진은 화면과 떼어 둔 순수 함수라, 정답지 테스트를 화면 없이 돌릴 수 있다.

1차는 6학년 하나로 ‘파일 → 진도표·엑셀’을 끝까지 잇고, 2·3차에서 대체에 필요한 기능과 협업을 채운다. 2028 편성 시즌 전 관문은 전 학년 자료로 정답지 테스트를 통과하는 것이다.

## 검증 계획

2026 신명초 6학년 파일을 넣었을 때 2026 실제 문서와 같은 숫자가 나오면 1차 통과다.

| 검증 | 넣는 것 | 맞춰 볼 것 | 시기 |
| --- | --- | --- | --- |
| 정답지 재현 | 2026 학사일정·행사 시트, 시간표 시트, 6학년 시수 증가 및 특성화 계획, 2026 진도표에서 뽑은 차시 | 시간 운영계획(1학기 555·2학기 537, 교과별 연간 시수), 교과진도 운영 계획 15개 표, 시수증감 행 8개, 학년별 수업시수 변동(6학년 1,092) | 1차 막바지(2027년 1월) |
| 스쿨마스터 병행 | 2027 6학년(또는 원진이 맡는 학년) 실제 자료 | 스쿨마스터 진도표·NEIS 엑셀과의 차이 | 2027년 2\~3월 |

- 정답지 테스트는 코드를 고칠 때마다 자동으로 다시 돌린다.

## 위험 요소와 대응

가장 큰 위험은 출판사 진도 데이터다. 스쿨마스터는 출판사만 고르면 되는데, 공용 진도 모음이 없으면 우리는 학교가 파일을 올려야 한다.

| 위험 | 영향 | 대응 |
| --- | --- | --- |
| 출판사 진도 데이터 | 가장 많이 쓰는 단계가 스쿨마스터보다 불편 | 공용 진도 모음(2차), 출판사 이용 허락을 2027년 상반기에 확인, 안 되면 학교별 업로드 유지 |
| NEIS 업로드 양식 미확인·변경 | 1차 핵심 출력이 막힘 | 스쿨마스터 출력 샘플·NEIS 양식을 가장 먼저 확보, 매년 양식 확인 |
| 파일 읽기 정확도 | 고칠 칸이 많으면 오히려 느림 | 2026 파일로 정확도 측정, 표준 엑셀 양식 제공 |
| 스쿨마스터 분석 범위 | 저작권·사용 계약 문제 | 직접 써 보며 기능·화면·출력 형식만 관찰. 실행 파일 역분석과 내장 데이터 추출은 하지 않음(법률 자문 아님) |
| 1인 개발 일정 | 담임·대학원과 병행라 늦어질 수 있음 | 차수별 범위 고정. 2027년엔 스쿨마스터와 병행하므로 늦어도 학교 업무에 지장 없음 |
| 운영·유지보수 | 다른 학교로 넓히면 갱신·문의·운영비 감당이 어려움 | 신명초 단계는 원진이 운영, 확장 때 주체 결정(연구회·교육청·유료화 등) |
| 학생 평가 기능 공백 | 평가 의견을 스쿨마스터로 넣던 교사는 다른 방법 필요 | 대체 범위 명시, 필요하면 학생 정보를 서버에 올리지 않는 브라우저 전용 모듈 검토 |
| 공공 도구 등장 | 평가원 AI 편성·시간표 시제품이 보급되면 겹침 | 차별점(파일 넣기, 단일 원본, 강사·어울림·진로, 부산 기준)에 집중, 동향 확인 |
| AI 비용 | 파일 읽기는 글자 수가 많아 비용이 큼 | 학교별 월 한도, 학교 자기 키 옵션(확장 때), AI 회사를 바꿀 수 있는 구조 |
