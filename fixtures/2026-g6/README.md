## 형이 할 일: hwp 3개를 hwpx로 (M4 전에)

1. 한글에서 `원본/`의 (c) hwp 파일을 연다.
2. [파일] → [다른 이름으로 저장하기] → 파일 형식을 **HWPX 문서(*.hwpx)** 로 고른다.
3. 저장 위치는 같은 `원본/` 폴더, 이름은 그대로(확장자만 .hwpx).
4. (d), (e)도 똑같이 한다. 원래 hwp 파일은 지우지 않는다.

끝나면 `원본/`에 hwpx가 3개 늘어 있어야 한다.

## 주의

- 원본에는 교사 이름이 있다. 기대값 JSON에 이름이 들어가면 안 된다(`tests/golden/privacy.test.ts`가 막는다).
- 원본끼리 서로 다른 곳이 있다(예: (d)와 NEIS1은 판본이 다름). 원본은 고치지 않고, 알려진 오류는 `expected/예외.md`에 적는다.
- 패들렛 원본은 절대 수정·삭제하지 않는다. 여기 있는 것은 사본이다.
